# Dictation

Dictation wandelt gesprochene Sprache auf deinem Windows-PC in Text um. Die Spracherkennung mit Whisper läuft lokal.

Download, Anleitung und Registrierung: https://thesimpilotcoder.github.io/dictation-releases/

Die aktuelle Setup-Datei und ihre Prüfsumme liegen im Ordner [`docs/download`](docs/download).

Dieses Repository enthält nur die Webseite und das aktuelle Setup. Der Quellcode von Dictation ist nicht öffentlich. Es gilt die [Lizenz](LICENSE).
